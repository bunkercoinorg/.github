# BunkerCoin

**The first blockchain running on radio waves**

BunkerCoin operates via shortwave radio signals instead of the internet, making it work without internet and pretty censorship-resistant. With shortwave ranges of 2,500-5,000 miles, global coverage is achieved with 10-20 nodes. Uses an adapted version of Alpenglow (Solana's next-generation consensus mechanism) for radio networks.

Explorer: https://explorer.bunkercoin.io/
